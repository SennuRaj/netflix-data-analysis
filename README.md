# netflix-data-analysis
Exploratory data analysis of the Netflix catalog using Python, Pandas, and Plotly.

# Data Analysis of Netflix's Content and Trends 🎬📊

## Overview
This project explores the vast content library of Netflix using data science techniques. By analyzing a comprehensive dataset of movies and TV shows, this project uncovers insights into genre distribution, country-wise content contributions, content ratings, and release year trends.

## Objectives
* **Content Volume:** Determine the ratio of Movies to TV Shows.
* **Genre & Directorial Popularity:** Identify the most prevalent genres and top directors.
* **Global Contributions:** Analyze content creation across different countries, with a focus on the USA and India.
* **Rating Distribution:** Understand the distribution of content ratings (e.g., TV-MA, PG-13).
* **Timeline Trends:** Track the growth and evolution of Netflix's content library over the years.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Plotly Express, Matplotlib
* **Environment:** Jupyter Notebook

## Key Findings
* **Movies vs. TV Shows:** The library is dominated by Movies (97.2%) compared to TV Shows (2.8%).
* **Top Genres:** Dramas (1,342 titles) and Comedies (1,029 titles) lead the platform.
* **Leading Countries:** The United States (1,653 titles) and India (832 titles) are the top content producers.
* **Target Audience:** The majority of content is rated TV-MA (Adults) and TV-14 (Teens).
* **Content Boom:** There was a massive surge in content added after 2015, peaking around 2018–2019.

## Project Structure
* `netflix_titles.csv`: The raw dataset used for analysis.
* `notebook.ipynb`: Jupyter Notebook containing data cleaning, transformation, and Plotly visualizations.
* `final project report.docx`: Detailed documentation of the project's methodology and findings.
* `Data-Analysis-of-Netflixs-Content-and-Trends.pptx`: Presentation slides summarizing the project.
